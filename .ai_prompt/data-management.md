# Data Management Guidelines

bb-code stores local project state in `.bb/` inside the active workspace.

## Local Files

- `.bb/settings.json`: model provider settings.
- `.bb/web_state.json`: active workspace and repo selection.
- `.bb/context.md`: repository context generated by `bb-code understand`.
- `.bb/diagnostics.md`: local diagnostic output.
- `.bb/reports/`: generated platform, refactor, and bug-risk reports.

Do not store secrets in logs, reports, or generated context. Redact tokens, API keys, passwords, kubeconfig credentials, and OAuth values.

## Reports

Reports should be reproducible from local scans plus read-only tool output. Prefer structured inventories and deterministic heuristics before model-written summaries.

## Kubernetes Data

kubectl access must remain read-only unless a future UI action explicitly asks for confirmation. Allowed default reads include contexts, namespaces, pods, deployments, services, and cluster info.
